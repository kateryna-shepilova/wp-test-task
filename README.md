## Requirements
- WordPress 6.x, PHP 7.4+ (8.1+ recommended)

## Installation
1. Copy this folder to `wp-content/plugins/`.
2. Activate the plugin in **Plugins**.

Local environment: install [`@wordpress/env`](https://www.npmjs.com/package/@wordpress/env), run `wp-env start` (Docker required) and open http://localhost:8888 (admin / password).

## Usage
- Shortcode: `[tt_example]`
- REST endpoint: `GET /wp-json/tt/v1/items`
